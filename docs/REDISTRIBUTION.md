# Redistribution review for Infinity OS

Reviewed 15 October 2026 against the `Infinity-GNOME-Live` and `Infinity-GNOME-Disk` image definitions. This is a release checklist based on the cited primary sources; the licenses and contents of the **built** ISO/RAW still need to be checked before publication.

## Fedora identity

Infinity OS combines Fedora packages with third-party software, so it is a Fedora Remix, not an official Fedora Spin. Fedora permits an independently branded remix. Its [Remix guide](https://fedoraproject.org/wiki/Remix) and [trademark guidelines](https://docs.fedoraproject.org/en-US/legal/trademarks/#_distributing_combinations_of_fedora_materials_with_non_fedora_or_modified_fedora_materials) require removal of `fedora-logos`, `fedora-release`, and `fedora-release-notes` for a mixed image, and a prominent notice that Fedora Project neither provides nor supports the image, with a link to [official Fedora](https://fedoraproject.org/). Do not imply Fedora or Red Hat endorsement. `teams/workstation.xml` requests `generic-logos`, `generic-release`, and `generic-release-notes` for the Infinity profiles and ignores the three Fedora packages plus `fedora-release-workstation`; verify the actual RPM manifest from **each** finished image because inherited package collections may differ. If using the exact “Fedora Remix” mark, follow its trademark conditions; “based on Fedora Linux” is a factual description of origin, not a claim of affiliation. [Sources: Fedora Remix](https://fedoraproject.org/wiki/Remix), [Fedora trademark guidelines](https://docs.fedoraproject.org/en-US/legal/trademarks/).

Suggested prominent notice for the download page and README: “Infinity OS is an independent Fedora Remix. It is not provided, supported, or endorsed by the Fedora Project or Red Hat. Official Fedora Linux is available at [fedoraproject.org](https://fedoraproject.org/).”

## RPM Fusion, codecs, and NVIDIA

The Infinity GNOME image selects RPM Fusion Free and Nonfree repositories, `ffmpeg`, `libavcodec-freeworld`, and GStreamer plugins in `repositories/infinityos.xml` and `teams/workstation.xml`. The proprietary NVIDIA driver is installed into the target system only when the installer detects a compatible NVIDIA GPU. RPM Fusion describes **Nonfree** as software under a nonfree license that is otherwise redistributable (including NVIDIA drivers), while its **Tainted** repositories have different restrictions. The current definition does not explicitly enable Tainted. RPM Fusion's repository classification is not a blanket patent or distribution clearance for every jurisdiction. Its FAQ specifically notes that rights beyond copyright can matter and that patented codecs are one reason Fedora does not ship certain software. [Source: RPM Fusion FAQ](https://rpmfusion.org/FAQ).

Distribution from Poland or elsewhere in the EU does not by itself settle codec patent exposure. The [European Patent Office](https://www.epo.org/en/news-events/in-focus/digital-innovations/patentability-digital-inventions) explains that software-based technical inventions can be patentable; [Poland's PARP](https://www.parp.gov.pl/component/content/article/85768%3Apatentowanie-programow-komputerowych) likewise distinguishes software “as such” from technical inventions. Before a public image release, identify the exact codec binaries and target distribution territories, then obtain a rights assessment if distributing patented formats. Do not claim that RPM Fusion packages are automatically lawful worldwide or that EU/Polish location alone removes the issue.

NVIDIA's current [driver license, §1.1(d)](https://www.nvidia.com/en-us/drivers/nvidia-license/) permits distribution for use with OSI-licensed kernels only if the binary files are unmodified (apart from decompression) **and the agreement is provided to each recipient**. Keep NVIDIA's notices, provide its license in the image or adjacent release materials, and check the exact license shipped by the RPM Fusion driver version selected for the release. The project's NVIDIA selection script changes package branches; it does not establish a broader redistribution right. [Source: NVIDIA driver license §§1–2](https://www.nvidia.com/en-us/drivers/nvidia-license/).

## Fonts and other bundled software

- **IBM Plex Sans 1.1.0:** 16 TTF faces are stored in `root/usr/share/fonts/IBM-Plex-Sans/`, with its OFL-1.1 text in `root/usr/share/licenses/infinityos-plex-sans/LICENSE.txt`. The [upstream IBM license](https://github.com/IBM/plex/blob/master/LICENSE.txt) permits bundling and redistribution with software if copyright and license notices travel with the font. “Plex” is a Reserved Font Name, so a modified font must use a different name. The current files are described as unmodified upstream faces. Describe the desktop as **using IBM Plex Sans**; do not suggest IBM endorsement.
- **Iosevka Term 34.9.0:** `root/usr/libexec/infinityos-install-iosevka` downloads and verifies four TTF faces during image build; its OFL-1.1 text is at `root/usr/share/licenses/infinityos-iosevka/LICENSE.md`. Preserve that notice in the finished image. The [upstream license](https://github.com/be5invis/Iosevka/blob/main/LICENSE.md) permits bundling and redistribution with software, subject to OFL conditions.
- **Proview v1.4:** `root/usr/libexec/infinityos-install-proview` downloads an architecture-specific, checksum-verified upstream AppImage during image build; the [upstream release](https://github.com/emanuelelongo/proview/releases/tag/v1.4) and [AGPL-3.0 license](https://github.com/emanuelelongo/proview/blob/v1.4/LICENSE) identify its provenance. The image carries the license at `root/usr/share/licenses/infinityos-proview/LICENSE.txt`. For distribution of the AppImage in an ISO/RAW, AGPL-3.0 §6 requires equivalent access to the **Corresponding Source**; place clear directions to the exact v1.4 source next to every image download, and keep it available for as long as the binary is offered. A license file alone does not meet the source-access condition. If Proview is changed or rebuilt, provide the corresponding modified source and notices. [Source: Proview license §6](https://github.com/emanuelelongo/proview/blob/v1.4/LICENSE).
- **Other components:** `THIRD_PARTY.md` inventories Orchis, Kora, GNOME templates, extensions, Ghostty, Powerlevel10k and icons. Retain their applicable license notices and source/attribution obligations in both architectures. The icon inventory includes product marks whose licenses or trademark permissions should be verified before claiming that all repo artwork is freely reusable. [Source: repository inventory](../THIRD_PARTY.md).

## Release checks

1. Inspect the actual x86_64 and aarch64 ISO/RAW package manifests for Fedora identity packages, RPM Fusion packages, exact driver licenses, and codecs; source definitions alone cannot prove the contents of a finished image.
2. Publish the independent-remix notice with each download and verify branded boot, installer, login, and desktop screens do not imply Fedora endorsement. [Fedora trademark guidelines](https://docs.fedoraproject.org/en-US/legal/trademarks/).
3. Offer Proview v1.4 Corresponding Source and NVIDIA's license alongside the image; preserve OFL and other third-party notices inside the image. [Proview AGPL-3.0 §6](https://github.com/emanuelelongo/proview/blob/v1.4/LICENSE), [NVIDIA license §1.1(d)](https://www.nvidia.com/en-us/drivers/nvidia-license/), [IBM Plex OFL](https://github.com/IBM/plex/blob/master/LICENSE.txt), [Iosevka OFL](https://github.com/be5invis/Iosevka/blob/main/LICENSE.md).
4. Resolve distribution-territory and codec patent questions for the **exact release** before making an image public. [RPM Fusion FAQ](https://rpmfusion.org/FAQ), [EPO](https://www.epo.org/en/news-events/in-focus/digital-innovations/patentability-digital-inventions).
