# Security policy

Infinity OS is in active development. Security fixes are handled on `main`; there is no separate supported release branch.

For a suspected vulnerability in Infinity OS code or image configuration, use [private vulnerability reporting](https://github.com/InfinityOS-linux/infinityos/security/advisories/new). Include affected versions, reproduction steps, and the potential impact. Please do not post exploit details in a public issue before a fix is available.

For vulnerabilities in Fedora, RPM Fusion, NVIDIA, or another upstream component, report to that project's security process as well. Infinity OS tracks and integrates upstream fixes; it does not replace upstream security support.
