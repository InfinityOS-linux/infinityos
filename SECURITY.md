# Security policy

Infinity OS is in active development and does not yet publish a verified release image. Security fixes are handled on `main`; there is no separate supported release branch.

For a suspected vulnerability in Infinity OS code or image configuration, contact the project owner privately through [the GitLab project](https://gitlab.com/godorowski/infinityos) or use a confidential GitLab issue when available. Include affected versions, reproduction steps, and the potential impact. Please do not post exploit details in a public issue before a fix is available.

For vulnerabilities in Fedora, RPM Fusion, NVIDIA, or another upstream component, report to that project's security process as well. Infinity OS tracks and integrates upstream fixes; it does not replace upstream security support.
