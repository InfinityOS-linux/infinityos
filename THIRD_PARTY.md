Performance configuration in `root/usr/share/infinityos/performance/` is adapted from [Bazzite's desktop zram, inotify, and networking settings](https://github.com/ublue-os/bazzite/tree/main/system_files/desktop/shared) and [Nobara's disk scheduler rules](https://github.com/Nobara-Project/rpm-sources/blob/main/baseos/nobara-login/60-ioschedulers.rules). These are configuration values and short udev rules, not bundled binaries.

InfinitySetup displays application icons bundled under `packages/infinity-setup/root/usr/share/infinityos/launcher-icons/`. Flatpak app icons come from the applications' Flathub metadata; Craft icons come from the corresponding [Storytold](https://github.com/storytold) repositories. OpenGamepadUI's icon comes from [its upstream repository](https://github.com/ShadowBlip/OpenGamepadUI), Docker's from [Simple Icons](https://simpleicons.org/), and the Claude and Codex icons from InfinityTerminal's existing assets. Product names and logos belong to their respective owners.

Orchis was built on Fedora 44 using `sassc` and `./install.sh -d /out -t purple -c dark -s compact --tweaks compact macos --shell 48` and the same command with `-c light`. Its complete upstream source at the pinned commit is archived at `assets/third-party/Orchis-theme-a4c48a425e63-source.tar.xz` (SHA-256 `5ac61bcba8117c339267b1f593b41716c42e668bf125eef8e07f637adfbe65f7`). The image bundles only the GNOME/GTK parts of the generated theme. The stylesheet needs a visual GNOME 51 test. The bundled User Themes extension loads the Shell theme; Fedora's `gtk-murrine-engine` provides the GTK 2 engine.

Infinity OS darkens the generated dark Orchis GTK 3, GTK 4, and GNOME Shell neutral surfaces and replaces light Shell submenus, quick-toggle menus, and overview search with dark purple variants. The original upstream source archive remains unchanged.

Kora's pinned source archive is `root/usr/share/infinityos/kora-v2.0.6.tar.gz` (SHA-256 `159bdb7a09409a12e54a71136ec8889c51b0bf7c145c8b20e3509dc1e90089bd`). The image setup extracts the main icon theme and license, regenerates its icon cache, and removes the archive from the installed system.

DING is unpacked from its pinned GNOME Extensions ZIP into `root/usr/share/gnome-shell/extensions/ding@rastersoft.com`; its GSettings schema is compiled during image setup. Bibata Modern Ice is extracted from `root/usr/share/infinityos/Bibata-Modern-Ice-v2.0.7.tar.xz` into the installed icon themes. Both are enabled only for Infinity OS profiles.

Five Fedora extension snapshots and the GNOME 51 Caffeine release above are stored under `vendor/gnome-shell/fedora-45/` with their GSettings schemas and license texts. `infinityos-shell-extensions` combines them with the modified extensions under `root/usr/share/gnome-shell/extensions/`, owns their installed files, and replaces the corresponding Fedora extension subpackages. GPaste's service and UI remain Fedora packages. Updating an extension snapshot requires a new tested Infinity OS RPM; ordinary Fedora updates do not replace these extension files. Powerline Symbols fonts, Firefox, drivers, and codecs continue to follow their signed package repositories.

The bundled Flathub remote descriptor (`root/etc/flatpak/remotes.d/flathub.flatpakrepo`) and signing key come from https://flathub.org/repo/flathub.flatpakrepo (retrieved 2026-10-12; SHA-256 `3371dd250e61d9e1633630073fefda153cd4426f72f4afa0c3373ae2e8fea03a`). No Flathub applications are bundled.

Image builds resolve the latest stable Proview and Iosevka releases. The versions above describe the checked-in installer defaults; `/usr/share/infinityos/upstream-versions.json` in each image records the actual upstream tags, source repositories, download URLs, and checksums. Corresponding Source links for distributed images must use those recorded tags.
