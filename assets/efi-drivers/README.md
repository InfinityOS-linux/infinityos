Infinity OS loads UsbXbox360Dxe v1.8.0 in rEFInd on x86_64 systems.

Source: https://github.com/jlobue10/UsbXbox360Dxe/releases/tag/v1.8.0
Binary: UsbXbox360Dxe.efi (standard release, x86-64 EFI boot service driver)
SHA-256: 9651e547d2842369e69776ce5fd51e5a2562268af91ca3ccfb80bf3f492d14a2
License: BSD-2-Clause-Patent (see root/usr/share/licenses/infinity-setup/UsbXbox360Dxe-LICENSE)

The driver accepts supported USB gamepads and receivers. It does not handle
Bluetooth controllers or aarch64 firmware. Infinity OS maps the D-pad and left
stick to arrow keys and A to Enter. Keyboard control remains available.
